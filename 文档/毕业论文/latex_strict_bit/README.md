# 严格 BIT 样式 LaTeX 模板

入口文件：`main.tex`

目录结构：

- `chapters/00_cover.tex`：封面
- `chapters/01_statement.tex`：独创性与授权声明
- `chapters/02_abstract_cn.tex`：中文摘要
- `chapters/03_abstract_en.tex`：英文摘要
- `chapters/10_chapter1.tex` ~ `12_chapter3.tex`：正文章节
- `figures/`：论文配图目录

编译：

```bash
xelatex main.tex
xelatex main.tex
```
